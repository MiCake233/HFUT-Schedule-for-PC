## 2. 架构

```
:app  (Kotlin Multiplatform library)
├─ commonMain        资源(Compose Resources)、共享模型
├─ jvmShared    ★     Android 与 JVM 同时 dependsOn 的中间源集，原 Android 源码绝大多数在此
├─ androidMain        Android 专属：Activity/WebView/相机/小组件/通知/快捷方式…
└─ jvmMain            桌面专属：Skia 图片解码、AWT 浏览器、空实现的日历/权限
:androidApp           Android 应用壳（applicationId 仍是 com.hfut.schedule）
:desktopApp           Windows 壳：窗口、主题、MSI 打包
```

### 2.1 平台边界（三种机制）

1. **expect/actual 能力对象**：`Platform`、`AppCapabilities`、`PermissionSet`、
   `PlatformStarter`、`OcrSupport`、`ClipBoardHelper`、`CalendarWriter`、
   `LanguageHelper`、`loadImageBitmap`/`pickColorFromTop`…
2. **类型化页面注册表**：`RenderPlatformDestination(destination)` —— 共享 Destination
   把 `Content()` 委派给它；Android 用 `when (destination)` 类型分发调用真实界面
   （参数随 Destination 对象走，不做字符串编解码），桌面返回 false 由占位兜底。
3. **组件槽位**：`UiSlots.register/render/action/updateChecker` —— 共享页面里的
   Android 专属子组件（电费、淋浴、慧新登录、课表设置面板、设置页…）在
   `MyApplication` 注册；桌面端可注册自己的替代实现（例如 `home_settings` 换成
   桌面版设置页），没注册就显示占位提示。

### 2.2 桌面端入口

`desktopApp/src/main/kotlin/com/hfut/schedule/desktop/`

* `Main.kt` —— `main()`：注入 `AppInfo`、开窗口；`--snapshot <png>` 离屏渲染验收
* `DesktopApp.kt` —— 主题（material-kolor 动态取色）+ `MainHost`（SharedNav 导航/转场）
  + 窗口级钩子（登录成功 / 退出）+ 注册 `home_settings` 槽位
* `DesktopRoot.kt` —— 根 Destination：协议页 → 登录页 → `HomeDestination`（=MainScreen）
* `DesktopSettings.kt` —— 桌面版「选项」页

## 4. 踩过的坑（避免重复）

1. **Gradle wrapper SSL PKIX**：本机 `github.com` 被 Steam++ 代理劫持，证书不可信 →
   换腾讯镜像 + 把代理根证书导入独立信任库（`tools\truststore\jdk-trust.p12`）。
2. **Compose 版本**：CMP 1.12.x 要 AGP 9.1 + compileSdk 37 → 降到 **CMP 1.11.1**；
   `lifecycle` 2.10.0（2.11 需要 compileSdk 37）。
3. **haze 1.6.2 桌面版**的 skia 着色器与 CMP 1.11 `ShaderBrush` 签名不兼容
   （`HazeProgressive` 抛 `NoSuchMethodError`）→ 能力位
   `AppCapabilities.supportsProgressiveBlur()`，桌面关掉渐进模糊、用渐变叠加等价实现。
4. **savedstate 双包冲突**（同包名两套 API）→ JetBrains navigation 从 2.7.0-alpha07
   升到 **2.9.2**，冲突消失；Android 端同样通过。
5. **AVD 静态化**缺 `xmlns:android` → 桌面解析抛 `SAXParseException`，补命名空间。
6. **离屏渲染必须在 AWT 事件线程**（`LiveData.addObserver` 要求主线程）→
   `SwingUtilities.invokeAndWait`。
7. **MSI 打包**的 WiX 从 github 下载被代理拦成 502 → 镜像下载后解压到 `tools\wix311`，
   设 `WIX_PATH` 环境变量即可离线打包。
8. **平台注册表不能靠字符串传参**：早期 key 携带参数的生成方案丢了参数解析，
   Android 端 65 个页面全退化 → 改类型分发。
