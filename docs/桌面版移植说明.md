## 2. 架构

```
:app  (Kotlin Multiplatform library)
├─ commonMain        资源(Compose Resources)、共享模型
├─ jvmShared    ★     由 androidMain 与 jvmMain 同时 dependsOn 的中间源集
│                     原先 861 个 Android 源文件绝大多数搬到这里，继续用 java.*
├─ androidMain        Android 专属：Activity/WebView/相机/小组件/通知…
└─ jvmMain            桌面专属：Skia 图片、AWT 浏览器、无操作日历…
:androidApp           Android 应用壳（applicationId 仍是 com.hfut.schedule）
:desktopApp           Windows 壳：窗口、主题、MSI 打包
```

### 2.1 平台边界

所有“只有一端有”的能力都收敛成 3 种机制，共享层不再直接引用 androidMain：

1. **expect/actual 能力对象**：`Platform`、`AppCapabilities`、`PermissionSet`、
   `PlatformStarter`、`OcrSupport`、`ClipBoardHelper`、`CalendarWriter`、`LanguageHelper`…
2. **类型化页面注册表**：`RenderPlatformDestination(destination)` —— 共享层 Destination
   把 `Content()` 委派给它，Android 用 `when (destination)` 类型分发调用真实界面
   （参数直接挂在 Destination 上，不做字符串编解码），桌面返回 false 由占位兜底。
3. **组件槽位**：`UiSlots.register/render/action` —— 共享页面里的 Android 专属子组件
   （电费、淋浴、慧新登录、校园地图…）在 `MyApplication` 里注册，桌面显示占位。

### 2.2 桌面端入口

`desktopApp/src/main/kotlin/com/hfut/schedule/desktop/`

* `Main.kt` —— `main()`：注入 `AppInfo`、开窗口；`--snapshot <png>` 支持离屏渲染验收
* `DesktopApp.kt` —— 主题（material-kolor 动态取色）+ `MainHost`（SharedNav 导航/转场）
* `DesktopRoot.kt` —— 根 Destination：协议页 → 登录页 → 主界面
* `DesktopHome.kt` —— 主界面：底栏 + Nav2 平切 + 课表/聚焦/查询中心/成绩/选项


## 4. 踩过的坑（重要，避免重复踩）

1. **Gradle wrapper SSL PKIX**：本机 `github.com` 被 Steam++ 代理劫持，证书不可信 →
   换腾讯镜像 + 把代理根证书导入独立信任库（`tools\truststore\jdk-trust.p12`）。
2. **Compose 版本**：CMP 1.12.x 要求 AGP 9.1 / compileSdk 37，Android 端无法接受 →
   降到 **CMP 1.11.1**；`lifecycle` 用 2.10.0（2.11 需要 compileSdk 37）。
3. **haze 1.6.2 桌面版**的 skia 着色器与 CMP 1.11 的 `ShaderBrush` 签名不兼容
   （`HazeProgressive` 会抛 `NoSuchMethodError`）→ 新增能力位
   `AppCapabilities.supportsProgressiveBlur()`，桌面关掉渐进模糊，用渐变叠加等价实现。
4. **savedstate 双包冲突**：JetBrains navigation 2.7 依赖旧版
   `org.jetbrains.androidx.savedstate`，与 CMP 1.11 需要的 `androidx.savedstate` 1.4
   同包名不同 API（`performRestore` 签名不同）→ 把 navigation 升到 **2.9.2**，冲突消失。
5. **AVD（animated-vector）静态化**：迁移资源时抽出的 5 个 `<vector>` 缺
   `xmlns:android`，桌面端解析直接抛 `SAXParseException` → 补命名空间。
6. **离屏渲染必须在 AWT 事件线程**：`ImageComposeScene` 里 `LiveData.addObserver`
   会抛 “must be called on the main thread” → 用 `SwingUtilities.invokeAndWait` 包起来。
7. **MSI 打包**：Compose 插件会去 github 下 WiX，被代理拦成 502 →
   用镜像下好后解压到 `tools\wix311`，设 `WIX_PATH` 环境变量即可离线打包。
8. **自动生成的注册表要靠类型分发**：早期用“key 字符串携带参数”的方案，
   生成器把参数解析代码丢了，Android 端 65 个页面全部退化 → 改成
   `RenderPlatformDestination(destination)` 类型分发，参数随对象走。
