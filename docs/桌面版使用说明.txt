HFUT-Schedule for PC  ·  Windows 桌面版 10.0.0
==============================================
适用系统：Windows 10 / 11（x64）

一、安装与启动
------------
1. HFUT-Schedule-10.0.0.msi
   标准安装包。按当前用户安装，无需管理员权限；安装时可选择目录。
   完成后在开始菜单与桌面生成快捷方式。已安装旧版本时可直接覆盖升级。

2. HFUT-Schedule-10.0.0-portable.zip
   便携版。解压至任意目录后运行 HFUT-Schedule.exe。该目录可整体复制或迁移。

二、首次运行
------------
1. 显示用户协议页，选择同意后继续。
2. 进入统一身份认证（CAS）登录页，输入学号、密码与验证码。
3. 登录成功后进入主界面。界面上方为周次、星期、通知与退出；中间为可排序卡片；
   下方为四个页签：课程表、聚焦、查询中心、选项。
   课程表打开时默认定位到当前周（按学期开始时间与系统日期计算），可左右切换。

三、登录状态与开机自启动
------------------------
1. 登录成功后，会话凭据保存于本机。下次启动时程序先恢复会话，成功后直接进入主界面，
   无需再次输入密码与验证码。
2. 会话过期或恢复失败时，程序回到登录页，重新登录一次即可。
3. 路径「选项 → 启动」提供三项设置：
   - 开机自动运行：写入当前用户的 Windows 启动项，登录系统后自动启动；可随时关闭。
   - 关闭窗口时最小化到托盘：关闭按钮改为隐藏窗口，由托盘菜单退出程序。
   - 退出登录：清除本机保存的登录状态。

四、系统托盘、桌面面板与提醒
----------------------------
1. 系统托盘：窗口关闭后驻留托盘，托盘菜单提供「显示主窗口 / 隐藏到托盘 / 今日课程面板 /
   面板始终置顶 / 退出」。命令行参数 --minimized 可让程序启动后仅驻留托盘。
2. 今日课程面板：「选项 → 桌面面板」开关。以独立小窗口常驻桌面，显示今日课程的时间、
   课程名与地点；每 5 分钟自动刷新，也可点击面板上的刷新按钮；窗口位置与大小会被记住。
3. 上课与考试提醒：「选项 → 提醒」开关，默认提前 20 分钟，可按 5/10/15/20/30/45/60 分钟切换。
   到点通过系统托盘气泡提示课程名、地点与开始时间。

五、数据备份与恢复
------------------
1. 「选项 → 数据 → 备份数据」：选择保存位置后，将本机数据目录打包为 zip。
2. 「选项 → 数据 → 恢复数据」：选择备份文件并确认后覆盖本机数据，程序随即退出，需重新启动。
3. 「选项 → 应用 → 检查更新」：读取 GitHub Releases 的最新版本号，若有更新可打开下载页。

六、功能范围
------------
1. 课程表：切换周次与学期、切换课表来源、拖拽排序、在空白格新建单次日程。
   课表网格设有宽度上限，窗口加宽时不会拉伸单元格。
2. 一卡通：余额、流水、账单分析、消费报表、限额。
3. 教务：成绩与 GPA 分析、考试成绩详情、考试安排、教学计划、总学分、挂科率、
   课程检索、教师检索、空闲教室。
4. 校园服务：图书馆检索与借阅记录、校车时刻、第二课堂、节假日、招生信息、
   校友、辅导员、淋浴使用码、电费、洗衣。
5. 生活服务：天气、校园地图、楼层导向、第三方应用、失物招领、通知中心。
6. Supabase：信息共建、日程、存储、网址导航。
7. 其他：AI 助手、校园邮箱、实验室、反馈。

七、桌面端的差异化实现
----------------------
1. 窗口尺寸与位置自动记忆。
2. 「添加到日历」改为导出标准 .ics 文件，保存于 用户目录\Downloads\HFUT-Schedule.ics，
   可由 Outlook、系统日历或手机日历导入，同一日程不重复写入。
3. 「导出教务课表」保存至下载目录并打开所在文件夹。
4. 网页类页面（体育、学信网、IETP、慧新等）由系统默认浏览器打开。

八、数据存放位置
----------------
Windows：%APPDATA%\HFUT-Schedule（登录状态、设置、卡片顺序）
卸载程序不会删除该目录；如需彻底清除，请手动删除。
