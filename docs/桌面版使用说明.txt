HFUT 课程表 · 桌面版（Windows）  版本 1.0.5
============================================

本目录里的两个文件，任选其一即可在 Windows 10 / 11 (x64) 上运行：

1) HFUT-Schedule-1.0.5.msi
   标准安装包（免管理员权限，按当前用户安装；安装时可以选择目录，建议选 E 盘）。
   安装完成后开始菜单 / 桌面会有带图标的「HFUT-Schedule」快捷方式。
   已装过旧版的话，双击这个包会**直接覆盖升级**，不需要先卸载。

2) HFUT-Schedule-1.0.5-portable.zip
   免安装版：解压到任意目录（如 E:\Tools\HFUT-Schedule），双击里面的 HFUT-Schedule.exe 运行。
   整个目录可以拷到 U 盘带走。

首次运行
--------
* 先出现「用户协议」页，点“同意”；
* 然后进入 CAS 登录页：学号 + 密码 + 验证码，与手机端完全一致；
* 登录成功后进入主界面（和手机端同一个界面）：
    顶部：周次 / 星期 / 通知 / 退出
    卡片区：余额、天气、校园网、明日课程……可拖拽排序
    底部：课程表 / 聚焦 / 查询中心 / 选项

电脑上能用的功能（1.0.5 已全部接上真实页面，不再是占位提示）
------------------------------------------------------------
* 课程表：切周、学期切换、多课表来源、拖拽排序、点空白格建单次日程，
  网格宽度有上限（窗口拉宽不会把课程格拉胖）
* 一卡通：余额、流水、账单分析、消费报表、限额
* 成绩 / 考试：成绩查询与 GPA 分析、考试成绩详情、考试安排、
  教学计划完成情况、总学分、挂科率、教师检索、课程检索、空闲教室
* 图书馆：馆藏检索、借阅记录；校车时刻；第二课堂；节假日；招生信息
* 生活服务：天气、校园地图、楼层导向、第三方应用、失物招领、通知中心
* 洗浴 / 水电 / 洗衣：淋浴使用码、电费余额与充值入口、洗衣机状态
* Supabase：信息共建、日程共建、存储、网址导航
* 其他：校友、辅导员（工作/招聘）、AI 助手、校园邮箱、实验室、反馈
* 查询中心的每一条功能，点进去都是真正可用的页面

桌面端新增的 PC 友好能力
------------------------
* 窗口大小/位置自动记忆，下次打开还是原来的样子
* 「添加到日历」在电脑上改为导出标准 .ics 文件
  （位于 用户目录\Downloads\HFUT-Schedule.ics，可用 Outlook / 系统日历 / 手机日历导入）
* 「导出教务课表」导出到下载目录并自动打开所在文件夹
* 网页类页面（体育/学信网/IETP/慧新等）自动用系统默认浏览器打开

已从界面移除的入口（Android 专属，电脑上确实做不到）
----------------------------------------------------
* 相机扫码
* WebVPN、办事大厅、淋浴登录（需要内嵌 WebView）
* 桌面小组件、快捷方式排序、控制中心磁贴、通知栏实时活动
* 学期报告（Android PDF 导出）、个人信息页
* 选课 / 退课 / 转专业
* 验证码自动识别（OCR）、AIDL 互联、应用内增量更新

这些功能的条目**不会出现在电脑端界面里**（不会再让你点进去看到"该功能依赖 Android 系统能力"），
需要用的话请在手机端操作。

数据存放位置
------------
Windows: %APPDATA%\HFUT-Schedule（登录态、设置、卡片顺序）
卸载时不会自动删除数据；需要彻底清除时手动删除该目录即可。

技术信息
--------
* 内置运行时：Temurin JDK 21.0.12.1（随安装包，无需另装 Java）
* 构建工具链：JDK 21 + Gradle 8.13 + Compose Multiplatform 1.11.1
* 图标：卡通风格自制徽标（非合肥工业大学官方校徽），避免版权问题
