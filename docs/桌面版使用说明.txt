HFUT 课程表 · 桌面版（Windows）
================================

本目录里的两个文件，任选其一即可在 Windows 上运行：

1) HFUT-Schedule-Setup-1.0.0.msi
   标准安装包（免管理员权限，按当前用户安装；安装时可以选择目录，建议选 E 盘）。
   安装完成后开始菜单 / 桌面会有带图标的「HFUT-Schedule」快捷方式。

2) HFUT-Schedule-1.0.0-portable.zip
   免安装版：解压到任意目录（如 E:\Tools\HFUT-Schedule），双击里面的 HFUT-Schedule.exe 运行。
   整个目录可以拷到 U 盘带走。

首次运行
--------
* 先出现「用户协议」页，点“同意”；
* 然后进入 CAS 登录页：学号 + 密码 + 验证码，与手机端完全一致；
* 登录成功后进入主界面（和手机端同一个界面）：
    顶部：周次 / 星期 / 通知 / 退出
    卡片区：余额、天气、校园网、明日课程……可拖拽排序
    底部：课程表 / 聚焦 / 查询中心 / 选项

主界面功能（与手机端一致）
--------------------------
* 课程表：左右滑动或点箭头切周、展开显示全部节次、多课表来源切换（含好友课表）、
  自定义背景（壁纸 + 顶部取色）、捏合缩放、导出/分享课表
* 聚焦：重要安排 / 其他事项 两页，下拉刷新，右上角“+”添加日程
* 查询中心：成绩、考试、空教室、课程汇总、学业预警、图书馆、校车、
  二手、失物招领等共享层已实现的页面（数据与手机端同源）
* 卡片：一卡通/余额/网费/天气等卡片，长按拖动排序
* 选项：桌面版设置页（版本信息、外观设置、WebVPN 状态、开源协议）

桌面端新增的 PC 友好能力
------------------------
* 窗口大小/位置自动记忆，下次打开还是原来的样子
* 「添加到日历」在电脑上改为导出标准 .ics 文件
  （位于 用户目录\Downloads\HFUT-Schedule.ics，可用 Outlook / 系统日历 / 手机日历导入，
   同一日程不会重复写入）
* 「导出教务课表」导出到下载目录并自动打开所在文件夹
* 所有网页（成绩详情、教务公告等）交给系统默认浏览器打开

电脑端做了降级的地方（Android 系统专属，PC 上没有等价物）
----------------------------------------------------------
* 扫码（相机）、验证码自动识别（OCR）、视频播放：显示占位提示
* 小组件（Widget）、快捷方式（Shortcut）、控制中心磁贴、通知角标：不做
* 内嵌网页（WebView）：改为用系统默认浏览器打开
* 「上课提醒 / 日历日程」面板（Live Activity、通知调度、写入系统日历）：
  桌面端显示占位提示，单条日程仍可导出 .ics
* 「选项」页里的部分设置项（备份、实验室、网络、教务密码等）：
  显示「该功能依赖 Android 系统能力」占位，可在手机端设置后同步

数据存放位置
------------
Windows: %APPDATA%\HFUT-Schedule
卸载时不会自动删除数据；需要彻底清除时手动删除该目录即可。
